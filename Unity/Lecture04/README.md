# RTGEF Unity Lecture04

Open in **Unity 6000.3.25f1**. Fetch Git LFS objects when cloning. Open `Assets/Scenes/ClipWorkshop.unity` and press Play.

- F1–F4: clips, Animator, root motion, rigging. R: restart scene.
- Animator: WASD/arrows or gamepad stick move; Shift/sprint runs; 1/2/3 select simple/1D/2D controller; E waves; Q toggles additive breathing.
- Rigging: I toggles IK; T pauses targets.

Focus the Game view for keyboard input or use navigation buttons. Stop Play to reset runtime scene changes; edits to clip/controller assets persist.

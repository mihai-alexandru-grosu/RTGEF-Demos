# RTGEF Unity Lecture05

Open this folder in Unity **6000.3.25f1** (URP 17.3.0, Input System 1.20.0). Open any scene in `Assets/Scenes`, press Play and click the Game view. Use the top scene buttons or F1-F4 to switch; the current scene is highlighted in gold.

- **F1 — Demo:** 1/2/3 select a target, Space activates it. Arrows move the listener; A/P/G/D toggle effects; T switches 2D/3D sound; M mutes ambience. Minus/Equals control SFX volume; brackets control ambience. R resets.
- **F2 — ParticleExamples:** six distinct particle stations. 1–6 focus, 0 overview, P pause/resume, Space/R replay.
- **F3 — DecalExamples:** quad and projected decals on different surfaces. Arrows move the centre projector, Minus/Equals resize, D toggles marks, B toggles the wall behind glass, R resets.
- **F4 — ShaderExamples:** texture/tint, separate RGB channels and a Shader Graph subgraph emission pulse. Inspect the editable graphs and materials in `Assets/Materials`.

Stop Play to return to the Editor scene state.

# Unity 3D lecture template

Open with Unity **6000.3.25f1**. Open `Assets/Scenes/Demo.unity` and press Play to view the starter cube and ground plane. No gameplay controls are included.

To reuse, copy `Assets`, `Packages` and `ProjectSettings`, preserving all `.meta` files. Do not copy generated folders such as `Library` or `Temp`. Set the new project's product name in Player Settings.

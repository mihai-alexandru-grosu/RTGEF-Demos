# RTGEF Unity Lecture02

Open this folder in Unity **6000.3.25f1**. Open `Assets/Scenes/Demo.unity`, press Play and click the Game view.

- WASD / arrow keys / gamepad left stick: move.
- Space / gamepad south button: jump.
- R or Restart: reset the demo and score.
- N or Next level: switch levels.
- B or Add bonus: load the bonus area.

Collect the spinning coins to increase the score. `Debugging.unity` is a separate scene with intentional faults for the debugging exercise. `BonusArea.unity` is loaded additively; do not run it alone.

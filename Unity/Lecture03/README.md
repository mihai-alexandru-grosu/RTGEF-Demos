# RTGEF Unity Lecture03

Open this folder in Unity **6000.3.25f1**. Open `Assets/Scenes/Platformer.unity`, press Play and click the Game view.

- A/D / arrow keys / gamepad left stick: move.
- Space / gamepad south button: jump.
- R: reload the scene and reset collected carrots.
- 1: Platformer; 3: TileWorkshop.
- Hold E: input-phase example; Shift+F: modifier-binding example.

Collect carrots and follow the level to the finish. `TileWorkshop` demonstrates tile editing and related 2D tools. Stop Play mode to finish.

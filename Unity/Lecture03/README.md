# Lecture 3 — Input System and a 2D game

Open this folder in **Unity 6000.3.25f1**. Start with `Assets/Scenes/Platformer.unity` and press Play, then click the Game view to give it keyboard focus.

This is the project Alex created at `Unity/Lecture03/Lecture03/`; its existing nested location is preserved. The original Sunny Land import and SampleScene are preserved. Teaching assets live under `Assets/`.

## Scenes and controls

| Scene | Purpose |
|---|---|
| Platformer | Sunny Land character, movement/jump, collectible carrots, animation, scrolling parallax, tile collisions and one-way platform |
| TileWorkshop | Editable terrain, palette, advanced Rule Tiles, open/closed Sprite Shapes, polygon collider, alternative input examples |

- A/D or Left/Right arrows: move; gamepad left-stick X also bound.
- Space or gamepad south button: jump.
- Hold E for 0.6 seconds: inspect Started, Performed and Canceled in the HUD and Console. A short press cancels before completion.
- Shift+F: modifier binding example, reported in the HUD/Console.
- 1 / 3: playable level / TileWorkshop.
- R: reload the current normal scene, resetting player and carrots.
- Falling below the platformer respawns the player at the start; collected carrots remain collected until R.
- Esc calls Quit in a standalone player; stop Play mode in the Editor.

The level extends to X=106, with home at X=100. Its final section integrates the effectors into the jump route: ride the conveyor at X=62–68, then jump right near its end across the gap to X=71. Walk into the wind lift at X=79, rise above the high ledge, then steer right onto X=82–88. Jump onto the one-way landing at X=90.5, then continue to the finish ground at X=94–106. Carrots mark the route. The earlier one-way platform remains at X=36.5; stepping terrain replaces the old wind lift location. The controller leaves horizontal velocity to the Surface Effector while idle on the belt. Directional input retains normal movement control.

## Walkthrough aligned to the current slides

Mapped against the 51-slide `2026/3. Making a 2D Game in Unity.pptx` inspected on 2026-10-04. The deck itself was not changed. Image-only slides are demonstrated through their surrounding topic.

| Slides / topic | What to show |
|---|---|
| 2–6: actions, maps, bindings, control schemes | Open `Input/Lecture03.inputactions`. Player/Move is a Value Axis with two 1D composites and gamepad binding; Jump is Button. Aim demonstrates a 2D Vector composite; Pointer is Pass Through. KeyboardMouse and Gamepad control schemes are defined. |
| 7: interactions and processors | Demo/Charge uses Hold; Demo/Modified uses a modifier composite. Move's gamepad binding has Axis Deadzone; Aim has Stick Deadzone. Hold/release E and inspect the phases. |

Inspect PlayerInput's actions, default map and Invoke C# Events behavior; observe the script's runtime fields while pressing keys. Stop Play to restore the saved example selection. |
| 12: generated C# class | Select the input asset and show Generate C# Class. `Assets/LectureInput.cs` is generated by Unity; `Scripts/GeneratedInputExample.cs` uses its typed Player properties. The active TileWorkshop example displays Move, Aim and Pointer values in the Inspector. |
| 13–14: 2D setup and components | Inspect orthographic camera, SpriteRenderer, Rigidbody2D, CapsuleCollider2D and trigger CircleCollider2D. Explain the separate 2D physics system. |

| 22–25: Grid, tilemaps, palette/tools | Open TileWorkshop in Edit mode. Open Window > 2D > Tile Palette, choose SunnyLand, select the practice tilemap, and demonstrate brush/box fill/picker/eraser/bucket and selection/move. Undo classroom painting to restore the saved scene. |
| 26–31: Rule Tile and outputs | Inspect `Tiles/ForestTerrain.asset` and paint adjacent terrain cells. Explain ordered rules, This/Not This, default sprite/collider and Single output. | 32–34: rotated, mirrored, extended neighbors | Inspect `ExampleRotated`, `ExampleMirrorX`, `ExampleMirrorY`, `ExampleMirrorXY`, `ExampleExtended`. The last rule checks a neighbor two cells away. | 35–37: collider types | Platformer Active tilemap combines TilemapCollider2D with a Static Rigidbody2D and CompositeCollider2D using Merge / Polygons. Toggle the composite operation in Play mode to compare outlines. Workshop rock demonstrates an editable PolygonCollider2D. Tile assets use Grid collision; custom sprite physics shapes require Sprite collider output to affect tile collision. |
| 38–41: effectors | In the playable level, stand on the conveyor, enter the wind lift and jump through the one-way platform. | 42–43: Sprite Shapes | In TileWorkshop Edit mode select the open curved path or closed outline, then Edit Spline. Show linear versus continuous tangents, move a point, inspect automatic collider updates, then Undo. The open path uses EdgeCollider2D; closed outline uses PolygonCollider2D. |
| 44–46: animation | Open `Animations/idle.anim`, skip, jump and fall in Animation. Inspect sprite keyframes and Player.controller transitions using Speed, VerticalSpeed and Grounded. Watch parameters while moving and jumping. |
| 47–50: parallax | Walk far enough to scroll Platformer's camera. Inspect the two source background layers: 0.85 and 0.55 factors; world props/terrain remain fixed. This asset pack supplies two background images rather than the four layers pictured in the slides. Higher factors follow the camera more closely. |
| 51: references | Use the lecture's references for further reading; no separate runtime feature. |

# Lecture 10 Effects Workshop

Open `Lecture10.uproject` in Unreal Engine 5.8.4. The project starts in `L_EffectsWorkshop`. Press Play.

| Control | Action |
| --- | --- |
| WASD and mouse | Move and look |
| 1 | Play the randomized Sound Cue in 2D |
| 2 | Play the same cue at the speaker |
| 3 | Switch the spatial motor between idle and fast |
| 4 | Fire the sprite flash and mesh burst |
| 5 | Toggle the CPU fountain between 24 and 110 particles per second |

Stop and restart Play to reset the workshop.
